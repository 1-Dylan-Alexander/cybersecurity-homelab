# Cybersecurity Homelab

## Overview

This repository documents the development of a hands-on cybersecurity homelab designed to build practical defensive security skills and reinforce concepts covered by the CompTIA Security+ certification.

The lab is built on a Lenovo ThinkPad T480 running Linux and uses virtualization to create an isolated environment for security-focused experimentation, configuration, monitoring, and analysis.

## Objectives

* Develop practical blue-team and defensive security skills
* Reinforce Security+ concepts through hands-on implementation
* Practice system hardening and secure configuration
* Develop foundational network security skills
* Collect and analyze security-relevant logs
* Practice security monitoring and detection
* Document investigative and incident-response workflows
* Build reproducible technical documentation
* Maintain a professional Git-based project history

## Projects

Projects will be added incrementally as the lab develops.

Each project will document:

* Objective
* Environment
* Configuration
* Implementation
* Security concepts demonstrated
* Evidence
* Findings
* Lessons learned

## Documentation Philosophy

The goal of this repository is to demonstrate the ability to not only perform technical tasks, but also document the reasoning, configuration, evidence, and results associated with those tasks.

All changes to the lab will be tracked through Git and pushed to GitHub as the project develops.
